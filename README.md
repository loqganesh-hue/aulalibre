## 🖥️ What aulalibre does

aulalibre is an unofficial client for Denmark’s Aula school platform.

It gives you a simple way to open Aula on your computer without using a web browser each time. This can make it easier to check school messages, view updates, and stay on top of daily school tasks from one app window.

## 🧩 Common issues

### App does not open

- Right-click the file and choose Run as administrator
- Check that Windows did not block the file
- Download the file again if the first download failed

### Sign-in does not work

- Check that your Aula login details are correct
- Make sure your internet connection is stable
- Try again after closing and reopening the app

### Screen looks blank or content does not load

- Wait a few seconds for the page to load
- Refresh by closing and reopening the app
- Make sure Aula itself is available and not having service trouble

### Download is missing

- Return to the releases page
- Look for the newest version at the top
